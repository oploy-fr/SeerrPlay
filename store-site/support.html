Help and issue reporting

Support

Before reporting a problem, verify that Seerr and the configured media server are reachable from the device.

Report an issue

Include the SeerrPlay version, device model, operating-system version and the error code shown by the application. Never publish passwords, tokens, API keys or private server addresses.

Open GitHub Issues

Third-party servers

Remote accounts, server availability and media content are controlled by the user's Seerr, Jellyfin, Plex or Emby administrator. SeerrPlay cannot reset those accounts or restore unavailable content.
